# iRich Documentation & Specifications

This directory contains the formal architectural blueprints, specifications, and design documents for **iRich**.

## Architecture & Design Index

1. [**`ARCHITECTURE.md`**](./ARCHITECTURE.md) - System overview, package boundaries, data flow, and runtime constraints.
2. [**`DOCUMENT_MODEL.md`**](./DOCUMENT_MODEL.md) - Canonical JSON schema, slots/children model, invariants, and migration strategy.
3. [**`COMPONENT_API.md`**](./COMPONENT_API.md) - Component registration contracts, prop schemas, slot definitions, and examples.
4. [**`EDITOR_API.md`**](./EDITOR_API.md) - Core state machine, command dispatching, React hooks (`useIRich`, `useNode`), and clipboard protocol.
5. [**`PLUGIN_API.md`**](./PLUGIN_API.md) - Extension model, lifecycle hooks, middleware pipeline, and custom plugin authoring.
6. [**`ROADMAP.md`**](./ROADMAP.md) - Phased implementation milestones and architectural trade-off evaluations.
