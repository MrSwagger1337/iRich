# @irich/ui

> Headless and styled UI primitives for the **iRich** visual editor.

---

## Features

- **Accessible Primitives**: Semantic HTML buttons, toolbars, and layout helpers with ARIA attributes.
- **Unopinionated & Themeable**: Built for high customizability and embeddability.

---

## Installation

\`\`\`bash
pnpm add @irich/ui
